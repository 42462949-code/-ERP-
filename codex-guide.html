适用于 Windows。按下面①②③④顺序操作，可点击图片单独放大，或下载PDF保存在电脑上。

这些图片是操作示意图，不是官网或您电脑的真实截图；界面可能略有不同。每张图片下方同时有文字步骤，图片暂时不显示也可以照文字操作。

1．下载 VS Code

打开微软官网下载页，选择 Windows 下载。下载完成后，在“下载”文件夹里双击 VSCodeUserSetup 安装文件；同意协议，安装位置保持默认。

保存第1张图片

2．完成安装

开始菜单名称保持默认；可勾选创建桌面图标，保持 Add to PATH 勾选，点击 Install（安装）。结束后勾选 Launch Visual Studio Code，点击 Finish（完成）。

保存第2张图片

3．安装中文和 Codex 扩展

按 Ctrl + Shift + X 打开扩展商店。搜索 Chinese (Simplified)，安装 Microsoft 的中文语言包并重启；然后搜索 @id:openai.chatgpt，安装发布者为 OpenAI 的 Codex 扩展。

保存第3张图片

4．登录并打开 ERP 源码

打开 Codex，选择 Sign in with ChatGPT，用您自己的 ChatGPT 账号登录。选择“文件→打开文件夹”，进入 E:\ERP系统\ 下您解压的项目，打开“源码”目录。应能看到 prototype、scripts、apps、README.md。确认工作目录后再发送开发任务。

保存第4张图片

打开源码后可以发送这句话

请先检查这个 ERP 项目的结构，后续在本地继续开发。修改页面后请运行构建脚本，保留我的表格数据。未经我明确要求，不要生成下载包。

后续开发后的页面入口是 源码/prototype/index.html。外层的 index.html 是发布快照，不会自动跟随源码改变。
